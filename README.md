# CrowdTune
Real-time crowd instability modeling system using computer vision and physics-inspired signal analysis.

Description
CrowdTune is a real-time crowd instability analysis system designed to model structural crowd risk before visible failure occurs. Instead of relying solely on density estimation or panic detection, the system interprets instability emergence through spatial constraint, kinematic activity, and collective coherence signals.

Core Framework
• Spatial Constraint (S)
• Kinematic Activity (K)
• Collective Coherence (C)

Feature Extraction
• Real-time optical flow tracking
• Crowd regime state analysis
• Interpretable instability indices
• Short-horizon forecasting
• PyQt6 dashboard visualization
• Multi-scenario validation
